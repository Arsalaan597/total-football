# Total Football — Project Charter

## Vision

Build a modular football analytics platform powered by machine learning, where specialised models work together under a central decision engine. Version 1.0 must meet the college assignment requirements while remaining a sound foundation for a longer-term project.

## Version 1.0 scope

1. Winner prediction
2. Goals prediction
3. Both teams to score (BTTS) prediction
4. Over/under 2.5 goals prediction
5. A decision engine that combines these outputs

## How we build

- Learn each concept before using it.
- Implement a simple version, verify it, then improve it.
- Keep code modular and explainable.
- Document decisions as we make them.
- Use meaningful Git commits to record the project’s evolution.

## Definition of success

By the end of version 1.0, we should be able to explain the data, every feature, preprocessing choice, model, and evaluation metric. A new contributor should be able to clone the repository and run the project using its documentation.
